# 可分类色图图库（二级目录 + 自动生成）

## 使用步骤

1. 按二级目录放图片：
   images/
   ├── 命运石之门/
   │   ├── 椎名真由理/
   │   │   ├── 01.jpg   ← 第一张自动当封面
   │   │   └── 02.jpg
   │   └── 牧濑红莉栖/
   └── 约会大作战/
       └── 夜刀神十香/

2. 运行生成脚本：
   python generate.py

3. 把整个文件夹上传到 GitHub，开启 Pages 即可。

文件说明：
- index.html  网站主文件（含18+免责声明）
- generate.py 自动扫描脚本
- data.js     分类数据（自动生成）
- images/     图片目录
